# 試験項目書とエビデンスの整合性チェックシステム

このシステムは、試験項目書とテスト実施時のエビデンス（ST-002）を比較し、エビデンスが試験項目書の試験観点を網羅しているかをチェックします。

## 機能

- **試験観点チェック**: 試験項目書の期待値→確認内容とエビデンス（ST-002）を比較
- **OK/NG判定**: エビデンスでカバーされているかを自動判定
- **画像検出**: エビデンスに画像ファイル（スクリーンショット等）が含まれている場合は「※目視で確認してください」と記載
- **自動入力**: 
  - 実施日：実行日を自動入力（YYYY-MM-DD形式）
  - 実施者：「湊」を自動入力

## 必要な環境

- Python 3.7以上
- openpyxl 3.0以上

## インストール

1. 依存ライブラリをインストール:
```bash
pip install -r requirements.txt
```

## 使用方法

### 前準備

1. 以下のExcelファイルをスクリプトと同じディレクトリに配置：
   - `試験項目書_ST_Ne-OpS名整合性チェック.xlsx`
   - `ST工ビデンス_Ne-OpS名整合性チェック.xlsx`

2. 試験項目書のシート構成：
   - シート名：「試験項目書」
   - カラム：「期待値」→「確認内容」（試験観点の説明）
   - カラム：「実施状況」→「結果」（チェック結果の出力先）
   - カラム：「実施状況」→「実施日」（実行日の出力先）
   - カラム：「実施状況」→「実施者」（実施者の出力先）

3. エビデンスのシート構成：
   - シート名：「ST-002」
   - 試験観点ごとの結果が記録されていること

### 実行

```bash
python check_evidence.py
```

### 出力

試験項目書の「実施状況」セクションに以下が自動入力されます：

- **結果**: 
  - `OK` - エビデンスでカバーされている
  - `NG` - エビデンスでカバーされていない
  - `※目視で確認してください\nOK` - 画像ファイルが含まれている場合（OK判定時）
  - `※目視で確認してください\nNG` - 画像ファイルが含まれている場合（NG判定時）

- **実施日**: 実行日（YYYY-MM-DD形式）
- **実施者**: 「湊」

## チェックロジック

1. 試験項目書の「確認内容」とエビデンス（ST-002）の試験観点をマッチング
2. キーワードが完全に一致、または部分一致した場合は「OK」
3. マッチしない場合は「NG」
4. エビデンス内に画像ファイル参照（.png、.jpg、.jpeg、.gif、.bmp、.tiff）が含まれている場合は「※目視で確認してください」と追記

## 対応する画像形式

- PNG (.png)
- JPEG (.jpg, .jpeg)
- GIF (.gif)
- BMP (.bmp)
- TIFF (.tiff)

### エラー: ファイルが見つかりません
- Excelファイルがスクリプトと同じディレクトリにあることを確認してください
- ファイル名が正確であることを確認してください

- Excelファイルのシート名が「試験項目書」または「ST-002」であることを確認してください

### エラー: カラムが特定できません
- ヘッダー行に「確認内容」「結果」「実施日」「実施者」の列があることを確認してください
